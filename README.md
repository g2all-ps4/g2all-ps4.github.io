# G2ALL

**A simple, multi-firmware PS4 GoldHEN host with automatic firmware detection.**

---

## 🎮 Supported Firmware

| Range          | Status |
|----------------|--------|
| 5.05 / 5.07    | ✅ Supported |
| 7.00 – 8.52    | ✅ Supported |
| 9.00 – 9.60    | ✅ Supported |
| 10.00 – 11.02  | ✅ Supported |
| 11.50 – 13.52  | ✅ Supported |

---

## ✨ Features

- 🔍 **Automatic firmware detection** — no manual selection needed
- 🧩 **Multi-firmware exploit support** — one host, every supported version
- 🔌 **GoldHEN integration** — seamless plugin loading
- 📦 **Offline cache support** — works even without a live connection
- 🪶 **Lightweight, static web host** — fast and minimal footprint
